# Revenue reporting calendars

Sources are captured; forecasts have not run. This study will compare simple fiscal-quarter and calendar-quarter pooled-growth forecasts with last year's same-quarter revenue on a fixed three-company cohort.

Eight official decoded JSON bodies are saved privately with observed HTTP200 responses and hashes: three Company Facts sources, three current Submissions sources and two source-listed history files. The source protocol preceded capture. Only structure, company identity and metadata coverage were inspected before the numerical design.

Read [the numerical protocol](NUMERICAL_PROTOCOL.md), [capture manifest](data/capture_manifest.json), [source protocol](PROTOCOL.md), [transport history](SOURCE_TRANSPORT.md) and [data rights](DATA_RIGHTS.md). Source reconciliation, method freeze, validation selection, protected test, rendering, privacy and release gates remain pending. Current filing-day reconstruction is an explicit assumption; immutable production point-in-time availability is unestablished. Formal-publication projects including Azure remain private.
